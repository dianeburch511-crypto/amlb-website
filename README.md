# American Made Line Builders, Inc. website

Static HTML website ready for GitHub Pages.

## Publish
1. Create a public GitHub repository (for example `amlb-website`).
2. Upload `index.html`, `.nojekyll`, and the `assets` folder (including `amlb-logo.svg`) to the repository root.
3. In repository **Settings → Pages**, under **Build and deployment**, select **Deploy from a branch**. Choose `main` and `/ (root)`, then **Save**.
4. Once deployment finishes, visit `https://YOUR-USERNAME.github.io/amlb-website/`.

## Contact form
The contact form uses `mailto:` and opens the visitor's configured email app; it does not directly submit messages. For a hosted submission form, connect a third-party form service or backend.

## Images and fonts
The page loads background photography from Unsplash and fonts from Google Fonts, so internet access is required for those resources.

## Notes
Please verify all office addresses and certifications before publishing.
